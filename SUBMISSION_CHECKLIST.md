# QVAC Bounty Submission Checklist

- [ ] App opens at `http://localhost:3000`
- [ ] `@qvac/sdk` is declared in `package.json`
- [ ] `loadModel()` is called
- [ ] `completion()` is called
- [ ] Inference is local through QVAC
- [ ] Public GitHub repository
- [ ] Open-source license included
- [ ] README included with install/run/version details
- [ ] At least 3 meaningful commits authored by you
- [ ] Screenshot or screen recording of the working app
- [ ] X post tags `@qvac`
- [ ] Submit GitHub repo URL + X post URL
